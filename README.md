# Interquartile Range (IQR) Analysis

## Description

This Python project calculates the **Interquartile Range (IQR)** of a dataset and visualizes the data using a box plot. The IQR measures the spread of the middle 50% of the data and is useful for identifying variability and potential outliers.

## Features

* Calculates:

  * First Quartile (Q1)
  * Median (Q2)
  * Third Quartile (Q3)
  * Interquartile Range (IQR)
* Displays results in the console.
* Visualizes the dataset using a box plot.

## Requirements

Install the required libraries:

```bash
pip install numpy matplotlib
```

## Libraries Used

* NumPy
* Matplotlib

## Sample Dataset

```python
data = [10, 12, 15, 18, 20, 22, 25, 28, 30]
```

## How to Run

```bash
python interquartile_range.py
```

## Output

```text
Q1 = 15.0
Median = 20.0
Q3 = 25.0
IQR = 10.0
```

A box plot will also be displayed showing the distribution of the data and the interquartile range.

## Applications

* Descriptive Statistics
* Data Analysis
* Outlier Detection
* Data Visualization

## Conclusion

This project demonstrates how to calculate the Interquartile Range (IQR) and visualize data distribution using Python, NumPy, and Matplotlib.
